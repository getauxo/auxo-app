AI 모델 (LLM) 연결

텔레그램으로 연결

이 에이전트를 텔레그램에서도 만날 수 있어요. 앱이 켜져 있는 동안 작동해요.

  1. 텔레그램 앱에서 @BotFather 를 찾아 대화 시작 → /newbot 으로 봇 만들기
  2. BotFather 가 준 토큰(긴 문자열)을 아래에 붙여넣기
✅ 와 연결됨 — 텔레그램에서 이 에이전트와 대화할 수 있어요.

디스코드로 연결

이 에이전트를 디스코드에서도 만날 수 있어요. 앱이 켜져 있는 동안 작동해요.

  1. Discord 개발자 포털 ↗에서 New Application → 왼쪽 Bot 메뉴로 봇 만들기
  2. Bot 화면에서 Reset Token으로 토큰을 받고, Message Content Intent를 켠 뒤 토큰을 아래에 붙여넣기
✅ 와 연결됐어요!

능력

기본 능력 · 항상 켜져 있어요

따로 설치할 필요 없이, 대화하면 에이전트가 알아서 사용해요.

  • 🧠 기억 — 중요한 걸 기억하고 떠올려요
  • 🔎 웹 검색 — 인터넷에서 최신 정보를 찾아요
  • 📁 파일 — 허락한 폴더에서 파일을 읽고 써요
  • ⌨️ 터미널 — 허락한 폴더에서 명령을 실행해요
  • 💻 코드 실행 — 파이썬·자바스크립트 코드를 돌려요
  • 🎙️ 음성 이해 — 보낸 음성 파일을 알아듣고 글로 옮겨요

    MCP 서버 (도구 확장)

    MCP 서버를 등록하면 그 도구를 에이전트가 사용해요. 명령을 실행하므로 신뢰하는 것만 등록하세요.

      문의·소개

      Auxo를 만든 이야기

      AI 에이전트가 좋다는 얘기는 많은데, 막상 써보려면 터미널을 켜고 설정을 만지고 키를 넣어야 했어요. 개발자가 아니면 시작부터 막힙니다.

      그게 아쉬워서 만들었어요. 내려받아 이름 하나 지어주면 시작이고, 그다음은 그냥 이야기하면 됩니다.

      대화도 기억도 이 컴퓨터에만 남습니다. 우리 서버로 보내지 않아요. 어떤 AI를 쓸지 직접 고르시고, 나중에 바꾸셔도 기억은 그대로 남습니다.

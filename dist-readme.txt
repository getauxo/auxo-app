============================================
  Auxo (오쏘) — 나만의 AI 에이전트  [테스트 버전 v0.1.0]
============================================

나를 알아가고, 필요할 때 도와주는 나만의 AI 에이전트예요.
설치 없이 폴더를 풀고 실행하면 됩니다. 모든 데이터는 본인 PC에만 저장됩니다.


■ 1. 실행 방법
--------------------------------------------
1) 이 폴더(Auxo)를 통째로 원하는 위치에 둡니다. (압축을 받았다면 먼저 풀어주세요)
2) 폴더 안의  Auxo.exe  를 더블클릭합니다.
3) "Windows의 PC 보호" 경고가 뜨면 (코드 서명을 안 한 테스트 버전이라 정상입니다):
   → [추가 정보] 클릭 → [실행] 클릭


■ 2. 첫 실행 — AI 모델(두뇌) 연결
--------------------------------------------
처음 켜면 에이전트를 만드는 화면이 나옵니다.
AI 모델을 연결해야 대화할 수 있어요. 가장 쉬운 방법은 무료 Gemini 키입니다.

[ Gemini 무료 키 발급 — 1분, 신용카드 불필요 ]
1) https://aistudio.google.com/apikey  접속 (구글 로그인)
2) [API 키 만들기 / Create API key] 클릭
3) 생성된 키(AIza... 로 시작) 복사
4) Auxo 첫 화면에서 "Gemini API 키로 연결" 선택 → 키 붙여넣기
5) 에이전트 이름을 지어주고 시작!

※ 다른 모델도 됩니다: 설정에서 Claude API / GPT(OpenAI) / 기타 모델(OpenRouter·DeepSeek 등) 키도 연결 가능.
※ "Claude 구독"은 이 PC에 Claude CLI가 설치돼 있어야 작동합니다 (일반 테스터는 위 Gemini 권장).


■ 3. 이렇게 써보세요
--------------------------------------------
- 평소처럼 대화하세요. 쓸수록 나를 더 잘 알게 됩니다.
- "내 이름은 OO야", "나 커피 끊었어" 처럼 알려주면 기억합니다.
- "내 OO 기억 지워줘" 라고 하면 잊습니다.
- 설정(우측 상단 ☰)에서 테마(다크/라이트), AI 모델, 프로필 사진 등을 바꿀 수 있어요.


■ 4. 개인정보 / 안전
--------------------------------------------
- 대화·기억은 전부 본인 PC에만 저장됩니다 (Auxo 서버는 없고, 아무것도 수집하지 않습니다).
- 다만 답변을 만들려면 대화 내용이 본인이 고른 AI 모델 제공자(Google·Anthropic·OpenAI 등)로 전송됩니다.
- 입력한 API 키도 본인 PC에만 보관되며, 에이전트 내보내기 파일에도 포함되지 않습니다.
- 키 사용료는 각 AI 회사 정책을 따릅니다 (Gemini 무료 티어는 일정량 무료).


■ 5. 문제가 생기면 (오류 기록 보내주세요)
--------------------------------------------
대화가 안 되거나 같은 오류 문구만 반복되면, 아래 파일을 보내주시면
원인을 바로 찾을 수 있습니다. 대화 내용이나 개인정보는 들어있지 않습니다.

  1) 키보드에서  Win + R  을 누릅니다.
  2) 아래를 붙여넣고 확인을 누릅니다.
       %APPDATA%\Auxo
  3) 폴더가 열리면  auxo-error.log  파일을 보내주세요.
     (파일이 없다면 아직 기록된 오류가 없다는 뜻입니다)


■ 6. 피드백 부탁드려요
--------------------------------------------
테스트 중 불편한 점, 안 되는 기능, 어색한 문구 등 무엇이든 알려주시면 큰 도움이 됩니다.
- 첫인상(온보딩이 이해되는지)
- 대화 품질 / 기억이 잘 되는지
- 버그(멈춤·오류 메시지 등)

감사합니다!
